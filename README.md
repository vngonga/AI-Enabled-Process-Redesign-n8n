# AI-Enabled Process Redesign Using n8n

**University of Utah | MSIS | AI for Business Process**

## Project Overview

Designed an AI-enabled customer return management workflow for a fictional retail company, RetailCo, using n8n and Figma/FigJam.

The project demonstrates how AI, deterministic ERP business rules, and human oversight can work together to improve operational efficiency while maintaining responsible AI controls.

## Technologies Used

- n8n Workflow Automation
- Figma / FigJam
- Large Language Models (LLMs)
- JavaScript
- Simulated ERP Data
- Business Process Mapping

## Key Features

- AI-powered extraction of order numbers, return reasons, and customer sentiment.
- Simulated ERP lookup and deterministic 30-day return eligibility validation.
- Automated routing of eligible, ineligible, and exception cases.
- AI-generated customer response drafts.
- Human review for missing order numbers, invalid orders, and escalated customer requests.
- Human approval before any customer response is sent.

## Business Value

The redesigned workflow demonstrates how organizations can reduce manual processing, improve consistency, and allow employees to focus on complex customer issues.

## Responsible AI

The prototype uses fictional data and does not connect to live enterprise systems. AI assists with language processing and drafting, while deterministic rules determine eligibility and humans retain final decision-making authority.

## Project Outcome

Completed an academic workflow redesign and n8n prototype demonstrating the integration of AI, business rules, exception routing, and human approval.
